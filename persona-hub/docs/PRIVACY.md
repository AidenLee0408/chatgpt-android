# 페르소나 허브 개인정보 처리 문서 (초안)

> ⚠️ **법률 자문이 아닙니다.** 이 문서는 엔지니어링 팀이 스펙(`docs/specs/functional-architecture.txt` 「개인정보보호법 대응」)과 현재 서버 코드를 바탕으로 만든 **골격 초안**입니다. 출시 전에 개인정보보호 전문 변호사나 CPO의 검토를 받아 확정해야 합니다. 조항 번호, 보유 기간, 국외 이전 수령자 정보(법인명, 연락처, 국가, 보관 기간)는 모두 **확인이 필요한 자리표시자**입니다. `〔 〕` 표시는 채워야 하는 값입니다.

## 1. 개인정보 처리방침 골격

1. **총칙**: 〔회사명〕(이하 "회사")는 「개인정보 보호법」 등 관련 법령을 준수하며, 페르소나 허브(이하 "서비스") 이용자의 개인정보를 다음과 같이 처리합니다.
2. **처리하는 개인정보 항목, 목적, 보유기간**: §2 표
3. **민감정보의 처리**: 건강 등 민감 등급 정보는 별도 동의를 받은 경우에만 처리합니다(법 제23조).
4. **고유식별정보 및 금융정보 미수집**: 주민등록번호, 카드번호, 계좌번호, 비밀번호는 수집하지 않습니다. 입력 단계에서 패턴을 감지해 저장을 차단합니다.
5. **개인정보의 제3자 제공과 국외 이전**: §3. 이용자가 직접 연결한 AI 서비스에 한해, 이용자가 선택한 범위만 전달합니다.
6. **개인정보 처리의 위탁**: §4
7. **개인정보의 파기 절차와 방법**: 탈퇴 즉시 모든 AI 연결을 끊고, 30일 유예 후 복구할 수 없는 방법으로 파기합니다. 백업은 〔N〕일 주기로 순환 삭제합니다.
8. **정보주체의 권리와 행사 방법**: §5
9. **안전성 확보 조치**: 민감 등급 봉투 암호화(KMS), 저장 및 전송 암호화(TLS 1.2 이상), 접근 토큰 단기 만료, 접근 기록 보관, 운영자 접근 감사 로그, 앱 생체 잠금
10. **자동 수집 장치**: 앱은 광고 추적 식별자(IDFA/GAID)를 수집하지 않습니다. 웹 동의 화면은 로그인 유지를 위한 세션 쿠키 1개(`ph_sid`, 1시간)만 사용합니다.
11. **만 14세 미만 아동**: 가입을 제한합니다. 〔연령 확인 방법〕
12. **개인정보 보호책임자**: 〔성명, 직책, 연락처〕
13. **권익침해 구제 방법**: 개인정보침해신고센터(118), 개인정보분쟁조정위원회(1833-6972), 대검찰청, 경찰청
14. **처리방침 변경**: 시행일 〔YYYY-MM-DD〕, 변경 이력

## 3. 국외 이전 고지

### 3.1 원칙
- 페르소나 데이터는 **국내 리전**(〔AWS 서울 ap-northeast-2〕)에 저장합니다.
- 국외 이전은 이용자가 해외 AI 서비스를 **직접 연결하고 동의 화면에서 허용한 순간**부터, **그 연결에서 허용한 페르소나와 등급 범위 안에서만** 일어납니다.
- 온보딩 팩트 분해에 외부 LLM(예: Anthropic API)을 쓰는 경우, 이는 별도의 처리위탁 겸 국외 이전으로 고지하고 동의받습니다. 답변 단위로만 전송합니다(스펙 기준).

### 3.2 고지 템플릿 (연결 동의 화면 W-02와 처리방침에 공통 사용)

| 항목 | 기재 내용 |
|---|---|
| 이전받는 자 | 〔법인명〕 (개인정보 보호책임자 연락처: 〔이메일〕) |
| 이전되는 국가 | 〔국가〕 |
| 이전 항목 | 이용자가 선택한 페르소나의 이름, 요약, 답변 지시, 허용 등급(일반, 또는 일반과 민감) 안의 팩트 |
| 이전 목적 | 이용자가 요청한 AI 대화의 개인화 |
| 이전 시기 | AI가 페르소나 허브 도구(list_personas, get_persona, search_facts)를 호출할 때마다 |
| 이전 방법 | 암호화된 네트워크(TLS)로 MCP 응답 전송 |
| 이전받는 자의 보유·이용 기간 | 〔수령자의 데이터 보존 정책에 따름. 링크〕. 연결을 해제하면 이후 전송은 즉시 중단됩니다 |
| 거부 방법과 효과 | 동의 화면에서 「거절」하거나 앱의 「연결」 탭에서 연결을 해제합니다. 거부하면 해당 AI에서 페르소나를 쓸 수 없지만 다른 기능은 그대로 이용할 수 있습니다 |

### 3.3 수령자별 초안 (⚠️ 법인명, 국가, 보관 정책은 각 사 DPA와 약관으로 확인해야 함)

## 7. 동의 화면 분리 (스펙 요구와 구현 체크)

- [ ] 가입: 필수(계정, 이용약관, 처리방침) / 선택(페르소나 정보) / **민감정보 별도 동의**를 각각 다른 체크박스로 받습니다. 기본값은 모두 미체크입니다.
- [ ] 국외 이전 동의: 연결할 때마다 받습니다(W-02). 위 §3.2의 8개 항목을 모두 표기합니다.
- [ ] 민감정보 동의가 없으면 「민감 포함」 선택을 막습니다(`SECURITY_REVIEW.md` M-4).
- [ ] 민감정보 동의를 철회하면 모든 연결을 `normal`로 낮춥니다.
- [ ] 동의 이력(항목, 버전, 일시)을 저장합니다.
- [ ] 출시 전 개인정보 영향 검토와 위탁·국외이전 목록을 **전문가 검토 후 확정**합니다.

> 다시 한 번 알립니다: 이 문서는 법률 자문이 아니며, 법령 해석과 표기 방식은 전문가 검토를 거쳐 확정해야 합니다.
