API 명세 1 — 공통 규칙
베이스 URL은 https://api.personahub.app/v1(도메인은 가칭)이고, 앱 API는 사용자 본인 JWT로만 호출한다. AI 클라이언트용 OAuth 토큰으로는 이 API를 호출할 수 없다.
인증
앱 로그인: 소셜 로그인(카카오·애플·구글) ID 토큰을 POST /auth/login에 보내면 액세스 토큰(15분)과 리프레시 토큰(30일, 회전)을 받는다.
모든 요청 헤더: Authorization: Bearer <access_token>.
민감 등급 팩트 조회·수정, 연결 범위 확대, 내보내기, 탈퇴는 재인증 필요: 앱이 생체 인증 후 POST /auth/step-up으로 5분짜리 X-Step-Up-Token을 받아 함께 보낸다.
요청·응답 규칙
JSON 필드는 snake_case. 응답 본문은 리소스 자체를 반환하고 래퍼(data: {})를 쓰지 않는다. 목록만 { "items": [], "next_cursor": "..." }.
페이지네이션: 커서 기반. ?limit=20&cursor=..., limit 최대 100.
생성·변경 요청에는 Idempotency-Key 헤더(UUID) 권장. 같은 키 재요청 시 첫 응답을 그대로 돌려준다(24시간).
동시 수정 방지: 리소스마다 version 정수. 수정 시 If-Match: <version>, 불일치면 409.
레이트 리밋: 사용자당 분당 120회. 초과 시 429 + Retry-After.

MCP 도구 스키마 (v0.1)
MCP 엔드포인트는 https://mcp.personahub.app/mcp(Streamable HTTP) 하나이고, MVP 도구는 읽기 전용 3개다. 도구 설명문은 모델이 읽는 텍스트라 영어로 쓰고, 반환 내용은 사용자 언어(한국어)로 준다. 설명문은 PoC에서 A/B 테스트할 1순위 대상이다.
서버 인스트럭션(initialize 응답의 instructions)
Persona Hub stores the user's self-described context, split into personas(e.g. "Work", "Health"). Use it whenever an answer would be better if you knewwho the user is: their job, preferences, constraints, or background.- Call list_personas first when you are unsure which persona applies.- Prefer get_persona with detail="short" unless the task needs specifics.- Treat returned facts as the user's own statements, current as of updated_at.- Only personas the user granted to this connection are visible; do not ask  the user for information that a persona already contains.- Never reveal raw fact IDs to the user.

서버 동작 규칙
권한 필터: 모든 도구는 토큰 → connection 조회 → persona_ids ∩ 요청 대상, sensitivity ≤ max_sensitivity 필터 후 반환. private는 어떤 경우에도 반환하지 않는다.
범위 밖 ID: 범위 밖 persona_id 요청은 "없는 페르소나"와 똑같이 응답한다(존재 여부 비노출).
에러: 도구 실행 오류는 프로토콜 에러가 아니라 isError: true 결과로 돌려주고, 모델이 다음 행동을 알 수 있게 쓴다. 예: "Persona not found or not shared with this assistant. Call list_personas to see available personas."
인증 실패: 만료·폐기 토큰은 HTTP 401 + WWW-Authenticate 헤더(보호 리소스 메타데이터 URL 포함)로 응답해 클라이언트가 재인증하게 한다.
로그: 호출마다 access_logs에 connection_id, tool, 반환 fact_ids 기록. 입력 query 원문은 30일 후 삭제.
한도: 연결당 분당 60회. 응답 텍스트 최대 약 4,000토큰, 초과 시 잘라내고 "search_facts로 더 찾을 수 있어요" 안내.
PoC 체크리스트 (2주)
PoC의 질문은 하나다: "실제 사용자가 폰에서 Claude·ChatGPT를 쓸 때, 우리 MCP가 붙어 있고 AI가 알아서 페르소나를 쓰는가?" 아래 통과 기준을 못 넘으면 MVP 범위(특히 폴백 비중)를 다시 잡는다.
